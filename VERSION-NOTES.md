## Hallow Toolkit 2.0 - Health, Games, Uninstall and the tray app

> History only - this version wasn't kept as a download. Get the newest version from the **Latest** release.

- **Health tab (new):** crash detective that explains each crash in plain English, memory info (warns when EXPO/XMP overclocking is on), one-click Windows memory test, drive health, driver age check, get the latest NVIDIA driver.
- **Games tab (new):** every installed game (Steam, Epic, Xbox and more) with size, store and last played, plus Play, Uninstall and Open folder.
- **Uninstall tab (new) - like Revo:** run a program's own uninstaller (restore point first), then scan for leftovers at Safe, Moderate or Advanced level. Files go to the Recycle Bin and registry items are backed up first. Plus a leftover finder for apps removed long ago.
- **Tray app (new):** Auto Game Boost closes the apps you pick when a game starts and reopens them when you quit. Panic key **Ctrl+Alt+End** force-closes a frozen game.
- **Gaming:** mouse acceleration on/off, shader cache cleaner, Auto Boost list.
- **Network:** internet speed test and which apps are using the internet right now.
- **Storage:** Downloads cleaner, project junk cleaner (Unity Library, node_modules...), duplicate finder.
- **Monitor:** CPU temperature tile (with the free LibreHardwareMonitor).

## Hallow Toolkit 1.0 - the first version

> History only - this version wasn't kept as a download. Get the newest version from the **Latest** release.

It started as a one-button "PC Optimizer" and became **Hallow Toolkit**: an orange H icon, a dark Halloween look, and six tabs.

- **Tune-up:** Quick Clean-up (temp files, crash dumps, Windows update cache, DNS flush, SSD TRIM, optional Recycle Bin), Health report, Update all apps (winget), Unblock stuck Windows updates, Repair Windows files (DISM + SFC), Weekly auto clean-up (Sundays 3 AM), Startup apps.
- **Monitor:** live CPU, RAM, GPU load, GPU temperature, GPU memory and network speed, plus drive space and the apps using the most RAM.
- **Gaming:** gaming tweaks (Game Mode, GPU scheduling), Balanced / High performance power plan, and a checklist to close background apps before you play.
- **Network:** ping test (latency, jitter, packet loss), network info, Flush DNS, Cloudflare DNS on/off, Reset network.
- **Storage:** biggest folders, huge files (1 GB+), empty Recycle Bin, Disk Cleanup.
- **Tools:** Copy my PC specs, Restart Explorer, Create restore point, Restart into BIOS, and quick links to Windows tools.

Long scans run in the background, anything risky asks first, and every action is logged.

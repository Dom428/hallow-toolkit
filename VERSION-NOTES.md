## Hallow Toolkit 3.0 - Tweaks, Dev and the first shareable zip

> History only - this version wasn't kept as a download. Get the newest version from the **Latest** release.

- **Tweaks tab (new):** privacy, quality-of-life and gaming switches with one-click Undo all; debloat preinstalled apps; startup manager (on/off or start 1 minute after boot); background services helper with Restore originals.
- **Dev tab (new):** port killer, dev cache cleaner (npm, Gradle, pip...), git status of all your projects.
- **Games:** game session recording (the tray app logs load, temps and VRAM while you play, with a chart), game save backup with optional weekly auto-backup, old clips finder.
- **Network:** game server ping by region, DNS speed test with "Use fastest DNS".
- **Health:** benchmark with saved history, sleep & wake doctor.
- **Storage:** Disk map - a clickable picture of what fills a drive.
- **Opens about a second faster:** shortcuts start it as admin directly, helpers are compiled once, the Monitor tab sets up only when opened.
- **Shareable:** packed as a zip with INSTALL.bat and a README, so friends can install it too.
